# AgentArts 环境登记与联调

本地模拟用于开发和测试业务闭环。真实平台的域名、区域、应用版本、鉴权和工作流变量必须以实际账号发布页面为准；没有完成以下检查前，不将模拟结果记为平台验收通过。

## 环境登记

| 配置 | 需要登记的信息 |
| --- | --- |
| 平台形态与区域 | 使用的产品形态、实际区域及对应官方 API 文档 |
| 应用 | 项目 ID、应用或工作流 ID、固定发布版本 |
| 调用地址 | 后端实际使用的运行地址；是否包含会话路径参数 |
| 平台鉴权 | 请求头名称、凭据配置位置、过期后的更新方式 |
| 工具地址 | AgentArts 可访问的 HTTPS 基础地址 |
| 工具服务认证 | 独立工具密钥的配置位置，不记录密钥原文 |
| 任务身份 | 动态 X-Task-Token 从可信节点进入请求头的映射 |
| 会话 | 业务 conversation_id 到平台会话 ID 的映射 |
| 请求映射 | 开始节点字段、业务上下文与受保护鉴权配置的位置 |
| 返回映射 | 完整回复及结构化结果位置；是否非流式 |
| 验证记录 | 负责人、时间、应用版本、契约版本、trace_id 与真实运行号 |

## 按顺序验证

1. 部署只读 T01，确认浏览器到后端、后端到平台、平台到工具后端三段分别可达。
2. 固定同一发布版本，查询 O001 和 O002；核对订单记录、工具运行记录和后端日志，不仅查看回复文字。
3. 验证服务密钥与动态任务凭据分别生效，伪造主体无效；再验证两个司机的会话和订单隔离。
4. 验证 T02 的条件必填、严格整数、幂等重放和冲突。
5. 验证 T03/T04 的 202 处理，未完成时返回 PROCESSING；持续轮询交给前端，模型每轮工具调用最多 8 次。
6. 验证调度批准与司机回执走人工接口，模型不能直接批准或激活。
7. 复现 20 分钟延误基准，以及变成 40 分钟后旧候选失效的案例。

如果平台不能受保护地注入动态凭据，只在固定模拟主体下演示，不宣称真实多用户权限验证完成。CORS 设置不会使云平台自动获得访问本地地址的能力。
