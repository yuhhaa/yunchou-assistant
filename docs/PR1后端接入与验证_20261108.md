# PR #1 后端接入与验证

日期：2026-11-08。来源：[PR #1](https://github.com/yuhhaa/yunchou-assistant/pull/1)，原提交 `ee713c723a490c88dd1bf3e1fcd301ceefcafadf`，以及《本地联调交接汇总_20261108.zip》。压缩包用于阅读交接说明；源码以 PR 为准，没有重复覆盖离线包。

## 接入内容

- DeepSeek 继续处理时读取已授权业务任务，复用有效影响分析；前端明确的分析/生成按钮直接调用业务接口，并刷新经后端核验的聊天状态。
- 修复未批准候选收到过早司机回执时的状态污染。
- 新增默认关闭的规则自动审核、审核来源字段、审计，以及前端提示。司机接收前只预留资源，不改变有效路线。
- 两套 Compose 和配置模板同步自动审核开关及阈值，不增加数据库迁移，迁移头仍为 0004。

本次评审核验后另补两项修复：

1. 旧失败或排队中的任务不再覆盖当前有效分析的聊天状态。新增回归先复现错误的 MANUAL_REVIEW/POLL，再验证恢复 GENERATE_PLANS。
2. 首版自动审核仅接受快照的 source、clock_mode、routing_source 均为 SIMULATION。任一真实或缺失来源都保留人工审批，审计记录 REAL_DATA_REQUIRES_MANUAL；启用开关不能绕过。实时位置和路况证据策略尚未实现。

## 本机更新与配置

已有演示环境升级前完成 PostgreSQL 备份；沿用原 Compose 项目、私有配置和数据卷，重新构建 API、计算/聊天 worker 与维护器，未重新 seed。更新前后均为 6 个用户、20 单、2 个事件、6 个方案、1 条已完成站点记录。

本机原前端仍使用 5177，后端 18084。源代码中的 API 端口仍按部署者自己的 .env 配置，8000 为模板默认值。这些回环地址不作为公网联调或云回调地址。

AUTO_APPROVAL_ENABLED 默认 false；本机现有演示配置保持关闭。按需启用前阅读[自动审核接入说明](自动审核接入说明.md)，API、worker、维护器一起重新创建，使开关与阈值一致。真实模型和地图凭据由各部署者保存在本地私有配置中。
