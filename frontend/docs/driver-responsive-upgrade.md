# 司机工作区响应式升级

日期：2026-11-03。范围仅限司机端模板布局、文案与 CSS；没有修改 store、API、JWT、轮询、审批、回执或后端状态。

## 修改文件

- src/views/Workspace.vue：标题改为今日配送，桌面导航与标题用正常文档流排列；异常反馈原区块移至右栏地图下方；保持原处理函数、条件、数据绑定与操作权限。
- src/driver-responsive.css：独立司机样式，限定在司机容器内；桌面约 35% / 65% 双栏、紧凑下一站卡、手机任务优先与小地图预览、触屏尺寸及焦点样式。共享调度样式不变。
- src/main.ts：导入司机样式。
- tests/driver-responsive.spec.ts：五档几何布局检查、导航、订单选择联动、无虚构 marker、地图展开/Escape/焦点恢复、异常上报对话框。

## 交互与视觉

桌面标题区压缩，导航不再绝对定位；下一站卡片约 255px 高，上报和到站按钮至少 44px。右栏地图缺数据时减少空白，异常反馈放在其下；选中任务仍联动详情。手机保留底部导航与安全停车提示，时间线排在地图之前，地图预览高 180px；展开模式不受预览尺寸限制。保留减少动画偏好。

真实 MapLibre 组件及地理适配校验入口沿用。当前没有实际坐标/几何，显示待接入，不新增虚构节点或路线，也不把点位连线当道路导航。

## 截图与对比

修改前实际启动浏览器，分别捕获 1600、1440、1280、768、390px，保存在 screenshots/driver-responsive/before/。修改后同宽度及操作场景截图位于 screenshots/driver-responsive/after/。均为明确标识的独立 DEMO；不是实际业务或模型验收。

桌面比改版前减少标题留白和下一站卡片高度；原大面积全宽反馈改为右栏内容，减少横向空白；手机不再让地图待接入区域阻挡任务列表。人工查看各档截图，修正标题行高、卡片间距与平板信息分布。

## 地图仍需后端提供

1. 授权仓库、配送点、车辆位置坐标与明确坐标系。
2. 位置采集/更新时间、来源与地理数据版本。
3. 当前/原计划及候选道路几何，绑定 snapshot_id/snapshot_version、route_revision 或 plan_id/plan_version。
4. 合法底图样式、瓦片与署名、浏览器公开配置。秘密凭据不能交给浏览器。
